 # Art-Logo-Project 

A creative web project that demonstrates how HTML and CSS can be used to design and animate logos without using external image files or graphic design software.

## Project Overview

CSS Art Logo Animation is a simple interactive website featuring three different logos created using CSS. The main webpage displays buttons for each logo, and when the user clicks on a particular button, the corresponding logo opens on a separate webpage with its CSS-based animation.
The project focuses on creativity, CSS styling, animations, transitions, and interactive webpage navigation.

 ## Features:
 
 -> Three different CSS-based logos.
 -> Interactive buttons for selecting logos.
 -> CSS animations and transitions.
 -> Separate webpage for each logo.
 -> Pure HTML and CSS implementation.
 -> Simple and responsive design.
 -> No external image files required for the logos.
 
## Technologies Used:

HTML5 – Website structure and navigation
CSS3 – Logo design, styling, animations, and transitions.

## How It Works -

- Open the main webpage.
- Three logo options are displayed.
- Click the button corresponding to the logo you want to view.
- The selected logo opens on a separate webpage.
- CSS animations are applied to create an interactive visual effect.

## Objective

The main objective of this project is to explore the capabilities of CSS for creating graphical designs and animations and to demonstrate how HTML and CSS can be combined to build an interactive and visually appealing website.
